# OPcalc

## Advanced Mathematics & Physics Calculator

OP Calc is a Python/Tkinter calculator designed for mathematics, physics, engineering, and scientific calculations.

It supports:

- Normal mathematical formulas
- LaTeX formulas
- Variables and starting values
- Automatic variable detection
- Solving equations for a selected variable
- Complex mathematical expressions
- Physics formulas
- Trigonometry
- Logarithms
- Powers
- Roots
- Fractions
- Integrals
- Derivatives
- Limits
- Summations
- Greek letters
- Exact and numerical answers
- Human-readable calculation steps
- LaTeX output
- Copying LaTeX results
- Saving `.tex` files
- Calculation history
- Loading previous calculations
